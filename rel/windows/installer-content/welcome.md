# OpenPairings

OpenPairings is tournament management software for chess arbiters: Swiss
pairings (FIDE Dutch), round robin, the Keizer system, FIDE tiebreaks,
result entry, standings, printing, and TRF/SWAR import and export.

By default this installs for your own Windows account only, with no
administrator rights required. If you have administrator access and want
OpenPairings available to every account on this computer instead, the next
step lets you choose that. A copy installed for everyone needs an
administrator each time it is updated, so installing for your own account
is the better choice unless someone looks after this computer for you.
